## STAGE 2 — COMPRESS: Graph-RAG

Create a `.codebase_context/` directory at the project root.

1. Generate `.codebase_context/INDEX.meta`
   - One line per file in the format:
     `<relative_path> | <type> | <one-line purpose> | <key symbols (comma-separated, max 5)>`
   - Keep the entire file under 6 KB total.
   - Group lines by category with a comment header:
     `# PAGES`, `# COMPONENTS`, `# HOOKS`, `# STORE`, `# SERVICES`, `# UTILS`
   - Example:
   # PAGES
    src/pages/UsersPage.tsx | page | Lists all users with search/filter | UsersPage, useUserSearch
    # COMPONENTS
    src/components/UserCard.tsx | component | Single user summary card | UserCard, userId, onSelect


2. For every component / page file, generate `.codebase_context/metadata/<filepath>.meta`
    - Format (plain text, keep under 300 tokens each):

FILE: src/components/UserCard.tsx
  PURPOSE: Displays a single user summary card with avatar and role badge
  COMPONENT: UserCard
  PROPS: userId (string), onSelect (fn), variant ("compact"|"full")
  HOOKS: useUser(userId), useState, useCallback
  RENDERS: Avatar, RoleBadge, Button
  USED_BY: src/pages/UsersPage.tsx, src/components/UserList.tsx
  STORE: reads userSlice.selectUserById
  STYLES: UserCard.module.css


3. For hooks and service files, generate `.meta` files listing:
   - What the hook/service does, parameters, return shape, and which components use it.

4. Generate `.codebase_context/ROUTES.meta` listing every route:
/ → src/pages/HomePage.tsx
/users → src/pages/UsersPage.tsx
/users/:id → src/pages/UserDetailPage.tsx
